# 模拟赛题：面向电力安全生产的"两票"智能审核与合规校核系统

> **性质**：自拟模拟赛题（体例对标第二届中国研究生智能建造创新大赛揭榜赛道赛题说明），锚定电力行业真实落地场景与公开规范依据。
> **目标产出**：GitHub 公开仓库 `power-operation-ticket-checker`（独立品牌，不复用 construction-drawing-plan-checker 代码，仅复用方法论）。
> **题目定稿日期**：2026-10-02

---

## 一、赛题介绍

"两票三制"（工作票、操作票；交接班制、巡回检查制、设备定期试验轮换制）是电力安全生产的核心制度。工作票与操作票审核目前存在突出痛点：

- **票据量大、人工审核效率低**：变电站/电厂操作票与工作票数量激增，审核维度繁多、标准不一（人民日报·中国能源报报道某操作票智能审核系统上线即为此痛点：字段抽取准确率 99%、文本审核准确率 92%）。
- **依赖专家经验、易漏审错审**：形式审核（必填项、签字流程）尚可人工覆盖；内涵审核（安全措施与工作任务的匹配、倒闸操作序列逻辑）高度依赖资深值班员经验。
- **审核标准不统一**：各单位执行细则差异大，同一问题不同审核人结论不同。
- **行业已有落地全部闭源**：商用系统、专利（CN116091030A 基于人工智能的两票管理系统）、企业大模型（青岛"光明大模型"两票编审智能体）均为闭源产品，**开源界没有像样的参考实现**。

本题要求参赛队伍研发一款面向电力生产实际场景的"两票"智能审核系统，实现工作票与操作票的自动解析、形式与内涵合规校核、依据关联与整改建议生成，形成**可开源、可复现、带内置评测基准**的一体化智能工具。

## 二、任务要求

### 1）票面信息自动识别与结构化

- **输入**：工作票（变电站（发电厂）第一种工作票、第二种工作票、电力线路第一种/第二种工作票、事故紧急抢修单）与倒闸操作票（变电站/电力线路），文本格式为主，打印体扫描件为加分项。
- **抽取字段**：票种、票编号、工作负责人/签发人/工作班成员、工作地点（设备双重名称）、工作任务、计划工作时间、安全措施条目、许可/签发/间断/转移/终结各环节人员与时间、操作票逐项操作序列。
- **输出**：统一中间表示（"票面参数卡"：字段-值-单位-置信度-证据{票样区域，原文摘录}）。

### 2）形式合规校核

- 必填项完整性与格式合法性；
- 时间逻辑（计划开始 < 计划结束；许可时间落在计划区间；终结流程完整闭环）；
- 流程完整性：签发→许可→监护→间断/转移→终结各环节人员签字齐全；
- 票种与工作内容匹配（第一种=需停电/需做安全措施，第二种=不需停电，抢修单适用范围），票样格式以 Q/GDW 1799.1-2013 / Q/GDW 1799.2-2013 附录为准。

### 3）内涵合规校核（核心难点）

- **安全措施完备性**：工作任务与安全措施匹配，覆盖保证安全的技术措施四要素（停电、验电、装设接地线、悬挂标示牌和装设遮栏）与组织措施五项制度（工作票、工作许可、工作监护、工作间断/转移和终结制度）——依据 Q/GDW 1799.1-2013 相关章节。
- **操作票逻辑校核**：倒闸操作序列合法性，围绕"五防"要求（防误分误合断路器、防带负荷拉合隔离开关、防带电挂（合）接地线（接地开关）、防带接地线（开关）合闸送电、防误入带电间隔）做形式化检查；五防口径入库时逐条挂规范原文出处核对。
- **一致性校核**：电压等级与设备双重名称一致、人员资质与角色匹配、操作项与安全措施互证。
- **风险分级与依据关联**：每条结论必须挂规范条款出处（标准号+条号+原文摘录），分为 合规 / 不合规（低风险/一般风险/较大风险/重大风险）/ 待人工确认 三级。

### 4）规范知识库构建

三层结构：规范原文 → 条文块（向量索引）→ 机器可读规则表（JSON：param/op/value/依据/级别/建议）。核心依据（均已查证官方源，入库时逐条挂出处）：

| 依据 | 编号 | 查证状态 | 来源 |
|---|---|---|---|
| 电力安全工作规程 电力线路部分 | GB 26859-2011 | 已核对编号与名称 | 国家标准全文公开系统 |
| 电力安全工作规程 发电厂和变电站电气部分 | GB 26860-2011 | 已核对（openstd.samr.gov.cn hcno=3428089C6475E0B29FF38B8C6D8EC205） | 国家标准全文公开系统 |
| 国家电网公司电力安全工作规程 变电部分 | Q/GDW 1799.1-2013 | 已核对（附录含操作票/第一种工作票票样） | 官方条文解读出版物 |
| 国家电网公司电力安全工作规程 线路部分 | Q/GDW 1799.2-2013 | 已核对（附录I 电力线路倒闸操作票格式、线路第一/二种工作票格式） | 同上 |
| 防止电力生产事故的二十五项重点要求（2023版） | 国能发安全〔2023〕22号 | 已核对（国家能源局官网原文 zfxxgk.nea.gov.cn） | 国家能源局 |
| 电力安全工作规程 发电厂和变电站电气部分（行业标准更新版） | DL/T 408-2023 | 编号已核对，条文待入库核对 | 行业标准 |

**版本纪律**：知识库每条挂"标准号+条号+渠道+status（待核对/已核对）"；查不到原文的条目显式标注"待核对"，不得以确定语气写入结论。

### 5）交互与交付形态

- **Web 面板**（免构建方案）：上传票据 → 票面参数卡 → 校核结论（三级分级+证据链）→ 报告预览；页面 0 外链、断网可演示。
- **报告导出**：docx（结论+分级问题清单+逐条证据+整改建议+签署栏）。
- **内置评测基准**：① 票面解析 F1（生成器真值 vs 解析结果，字段级 P/R/F1）；② 端到端校核（植入已知缺陷的检出率/误报率）。基准零 API 依赖可重复，指标写进 README。

## 三、提交材料

1. 系统/原型（网页版或 PC 客户端）：票据处理、规则校核、结果展示；
2. 核心代码框架：GitHub 公开仓库（解析/参数卡/规则引擎/RAG/报告/Web 分层，含自评基准脚本）；
3. 技术报告：技术路线、模型与算法设计、数据集构建、测试效果与应用分析；
4. 自制模拟数据集与生成器（带真值、固定 seed 可复现，含植入缺陷的配对评测集）；
5. 演示视频（≤5 分钟）：展示审核过程与输出报告。

## 六、边界与非目标（防 scope 失控）

- **不做**：SCADA/生产管理系统实时对接；真实电力公司内部数据；移动端 App；手写体 OCR（打印体扫描件识别仅作加分项）。
- **品牌隔离**：不复制 construction-drawing-plan-checker 代码，不提"施工图/方案"业务；仅复用方法论与工程模式。
- **数据合规**：全部模拟数据自制，设备名/人名/单位名虚构脱敏；数据台账登记来源与许可。
- **结论纪律**：数值与条文结论只来自确定性规则+已核对依据；LLM 仅兜底抽取、复核与行文；无出处的规则不得落库。
