# ticket_templates 票样模板（M1）

7 票种票样模板：字段清单重构自 Q/GDW 1799.1-2013 / Q/GDW 1799.2-2013 附录票样结构（字段名与内容全部自拟虚构，不入官方原文）。

## 组成

- `<票种代码>.txt`：模板布局（`{{key}}` 占位符；`steps`/`measures` 为生成器展开的多行块；缺失注入时保留『标签：』空值行）。
- `templates.json`：字段注册表（机器可读）——每字段登记 label/role（scalar|list|ambient）/required/injectable_missing/**source（对应票样结构位置）**/status；生成器与 M2 解析器的共同输入。
- 测试守门：占位符与注册表键一一对应（tests/test_data_generator.py）。

## 重构偏差（有意为之，避免解析歧义）

- 官方票样『工作班人员（不包括工作负责人）』重构为『工作班成员』：原标签内嵌字段名（工作负责人）会让行级正则误配。
- 文本格式将表格类栏目（安全措施、操作序列）线性化为『序号+条目』多行块；计划工作时间合并为一行『自…至…』。
- 抢修单环节精简为许可（值班负责人）+开始/结束时间，间断/转移环节不设（待 M3 原文核对）。

每个模板登记：字段清单、槽位正则约束（M2 解析器输入）、与 Q/GDW 附录票样结构的对应关系（templates.json 逐项 source 挂出处）。
