# generator 数据生成器（M1）

程序化自制带真值数据是核心资产：固定 seed 可复现、可注入已知缺陷做配对评测（评测零成本重复）。

- 输入：票种 × 正常/缺陷注入参数
- 输出：`*.txt` 票据文本 + `*.truth.json` 真值
- 真值语义：注入项记 `expect`（主期望结论），同一注入隐含的其余结论记 `also_expect`，评测按"全部非 pass 集合"对账
- 缺陷类型与规则 check_type 对齐（缺必填/时间倒挂/流程缺环/票种错配/措施缺项/五防违例/一致性不一致）
- 已知坑：同一参数互斥注入矩阵；多值封顶防组合爆炸；重生成前清空输出目录
- 验收：`--force` 重跑 git status 零变化（位级一致）
